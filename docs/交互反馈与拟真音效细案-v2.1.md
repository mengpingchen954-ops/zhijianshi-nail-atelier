# 《指间诗》交互反馈与拟真音效细案 v2.1

日期：2026-10-21  
性质：对《美甲工作室升级策划案 v2》的追加要求，属于核心体验验收项。当前仅完成设计，尚未制作音频、动画或游戏功能。

## 1. 体验目标

每个动作应让玩家明确知道：选中了什么、是否接触、正在改变哪里、变化到什么程度、何时完成、哪里需要修正。

反馈鲜明以因果关系清楚为标准。近景展示工具接触和材料变化，声音表达材质和节奏，界面说明当前状态。精细操作时保持镜头稳定，粒子、光效和提示不遮住甲缘。

所有核心状态在静音时都应可辨识。开启声音后，能听出刷、锉、棉片、瓶盖、甲片和灯具的区别；不以通用电子“叮”代替工具声音。

## 2. 统一动作状态

每项连续操作至少覆盖以下状态：

| 状态 | 视觉与交互 | 声音规则 |
|---|---|---|
| 选中 | 工具进入手持位，目标范围可见 | 一次轻拿起/抽出声音 |
| 悬停 | 有效区域轮廓、工具朝向与接近距离 | 通常安静；不悬停一次就反复响 |
| 接触开始 | 工具落到准确接触点，局部立即响应 | 接触起音，与实际接触一致 |
| 持续操作 | 甲面随路径变化，进度来自实际处理区域 | 连续材质声随动作变化 |
| 暂停或离开 | 工具抬起，材料变化停止 | 接触声平滑停止；电机本体声另算 |
| 单次动作结束 | 本次笔画/锉磨/擦拭收尾 | 短收尾，避免硬切爆音 |
| 阶段完成 | 对应指位和步骤更新，目标轮廓收起 | 仅一次克制的完成提示，可关闭 |
| 条件不符 | 标出具体原因和处理入口 | 一次柔和提示，不持续警报 |
| 返工 | 标出影响范围，保留其余施工结果 | 由实际工具动作发声 |
| 取消或切换 | 工具收回，无残留接触动画 | 停止对应循环；不播放成功音 |

完成音按阶段触发，不按每次鼠标移动触发。撤销、重做和恢复存档不能重播一整串旧施工音。

## 3. 接待与顾客手部表现

- 顾客入座有轻微椅子、衣料与桌面接触声，不强制播放长过场。
- 手机或参考卡放到桌面时，物件有落位动画和轻碰声。
- 手放到手枕时有姿势过渡和软垫受压表现，手腕不会悬空滑动。
- 检查时可抬指、转到侧面或自由缘视角；镜头切换保持短且可中断。
- 手术般精细的操作期间，顾客手部保持稳定。待机小动作只在停手时出现。
- 顾客反馈以表情插画/头像、文字和手势即可起步；语音是后续资源项，不假设已经具备。
- 允许轻微自然呼吸与放松姿态，不用突然缩手或随机抖动制造失误。

## 4. 修形、表面处理和电磨

这三者使用不同工具、目标区域与音色，不共用一个“打磨”按钮。

### 4.1 手工锉修甲形

流程：选择目标长度和甲形 → 观察自由缘 → 拿锉 → 沿边缘操作 → 检查左右轮廓 → 刷净粉尘。

反馈要求：

- 锉面朝向随接触边缘调整；靠近皮肤或无效区域不继续削去材料。
- 只在有效自由缘有实际修短/修形结果。不能靠滑动锉刀改变甲床长度。
- 轮廓以小步变化连续接近目标，不能开始拖动后突然整甲切换预制形状。
- 接触处出现少量细粉，已产生的浮尘保留到刷净；粒子数量受控。
- 提供目标轮廓与偏差提示，也可查看侧面，不用遮挡甲面的巨大进度圆。
- 速度快时摩擦节奏更密，停手即停止摩擦。接触材料不同，使用相应素材变化。
- 接近不可继续修短的界限时，显示清晰限位和原因；不靠痛叫反馈越界。
- 鼠标以路径、速度和接触区域判断，不假称能测量真实按压力。若需要力度玩法，采用显式滑杆/档位；触笔压力作为可选增强。

### 4.2 表面轻磨与抛光

- 表面处理使用大而柔和的接触区域；目标是按配方准备表面或修整已固化材料。
- 处理区域的光泽和粗糙度逐渐变化，并能观察漏磨区域。
- 手工锉的颗粒摩擦、海绵抛光块的柔细摩擦分开录制。
- 已充分处理区域不鼓励反复刷进度；界面明确提示“此处已完成”。
- 按当前层和服务说明动作目的，不能把所有阶段统一称为“磨本甲”。

### 4.3 电磨

- 电磨属于进阶工具，接入卸旧/修整时必须有对应材料和范围。
- 电机启动有短加速，空转有低音量机身声，触及材料后叠加摩擦声。
- 离开甲面只停止接触摩擦；关闭工具才让电机收转停止。
- 视觉展示打磨头旋转、接触点和局部材料减少，不夸张到工具整只乱抖。
- 声音保留设备特征，但控制刺耳高频；提供降低电磨声音的选项。
- 不以多次高强度磨薄本甲作为奖励路径。具体工具适用范围后续专业审核。

## 5. 照灯与固化完整流程

照灯是材料状态变化的步骤，不是点按钮后立刻获得一个完成标记。

### 5.1 开始前

- 当前服务配方决定哪些层需要固化、哪些指已经就绪。
- 选择照灯时显示本次手指和待固化层，逐指检查前置条件。
- 未处理的明显溢胶、未完成的贴合和仍需调节的磁吸布局提供具体提示。
- 展示手放入灯内的动画，位置反馈明确；姿势无法覆盖某指时提示调整或单独处理。
- 可以由系统辅助摆好手，不能把细小姿态调整变成每次重复的障碍。

### 5.2 运行中

- 启动按钮有按下动作、真实按钮声；所选灯型有提示蜂鸣器时才发启动提示音。
- 灯内局部发光，甲面和手部有对应受光；不使用全屏强闪。
- 倒计时与材料固化状态同时可见，灯光本身不是完成证明。
- 如果所选灯型带风扇，播放低音量运转声；没有风扇的设备保持安静，不虚构“紫外线嗡鸣”。
- 游戏用短等待压缩流程，提供加速/跳过等待动画，结果只按规则完成，不让玩家重复空等。
- 显示的秒数为游戏计时，不能作为现实材料固化时长建议。
- 提前取手进入“本次固化未完成”，保留层状态并提示重新处理；首版用简明规则重新完成本次固化，不估算现实曝光剂量。

### 5.3 结束后

- 提示音只响一次，随后关闭灯光，手自然移回手枕。
- 本次适用手指更新固化状态，其他手指保持原状态。
- 已固化胶层在游戏中不再像湿胶一样拖动；是否需要清洁表面残留，取决于材料配方，不统一处理。
- 磁吸布局锁定，转手仍保留光泽变化；要改布局必须走对应返工。
- 哑光封层完成后保持哑光，不能统一增加强高光作为“固化成功”特效。
- 手动暂停或浏览器切后台时，游戏计时与声音同时暂停，返回后明确恢复状态；不得后台播完声音但施工状态没变。

底层、建构、猫眼色层和封层分别管理固化状态，批量操作也不能跨越各自前置条件。

## 6. 其他工具与工艺的反馈清单

| 操作 | 可见变化 | 写实声音与触发条件 |
|---|---|---|
| 取放刷子/锉条 | 物件离开工具盘，回位后稳定落下 | 与工具盘材质匹配的轻碰声，每次取放一次 |
| 开合瓶盖 | 旋转、脱开、收紧 | 螺纹与瓶盖声；按瓶型区分 |
| 蘸取胶液 | 刷毛携带材料，口沿轻刮 | 克制的湿润和刷口声，不夸张冒泡 |
| 软刷清洁 | 刷毛接触，污垢逐渐减少 | 轻扫声随路径出现，离面停止 |
| 清洁棉擦拭 | 棉片轻贴，残留沿轨迹减少 | 柔软纤维摩擦，干湿有区分 |
| 修锉后除尘 | 积留粉尘被扫走 | 软刷声，与锉磨声有明显区别 |
| 处理旧材料 | 旧层局部变薄或松动 | 依所用工具发声，材料不凭空响 |
| 卸除旧片 | 处理后脱离，露出本甲和残留 | 轻接触/置于盘中声，不设计暴力撬断声 |
| 选片试贴 | 两侧覆盖、曲率和中心线可比较 | 甲片拿取、轻落位声 |
| 放置贴合材料 | 贴合区逐渐覆盖 | 少量黏性细节，仅在实际动作发生 |
| 甲片贴合 | 偏移、间隙和气泡随调整变化 | 轻贴合声；气泡用视觉表达，不做泡泡爆破音 |
| 剪短人工甲片 | 剪具闭合，余片分离并被收集 | 短促清脆剪切声，单次触发 |
| 建构放胶与铺胶 | 胶量、顶点、溢边和厚薄可见 | 刷毛接触与微量黏性声，不能像搅大盆液体 |
| 上底色 | 颜色随刷动覆盖，露底与越界可见 | 细腻刷涂声，随速度和接触变化 |
| 渐变点拍 | 分界逐步变柔和 | 海绵轻拍或刷涂声，按选用工具区分 |
| 法式描边 | 微笑线沿路径形成 | 细刷声；模板贴下与揭起另有短声 |
| 猫眼磁吸 | 光带随位置/方向/距离改变 | 光带本身不发声；工具实际拿放才有声音 |
| 揭取贴纸 | 贴纸从底纸分离，边缘弯曲 | 轻揭膜声，2D 设计板可用更轻的纸感提示 |
| 贴纸压平 | 从接触点贴合，边缘平顺 | 轻压/抚平细节，不每个像素都触发 |
| 镊取水钻/珍珠 | 镊尖准确夹持，落位后有立体投影 | 镊子轻碰、饰品与托盘接触声；按材质区分 |
| 金箔/亮片 | 指定区域出现疏密变化 | 工具擦拭、容器声音；细颗粒本身通常很轻 |
| 镜面粉 | 甲面反射逐渐改变 | 涂抹工具的细摩擦，无强金属撞击声 |
| 晕染/大理石 | 纹理扩散并停止在可控范围 | 主要是点涂工具声，不让颜料扩散持续冒泡 |
| 涂封层 | 覆盖区域与材质效果可见 | 细刷涂声；完成光泽由所选封层决定 |
| 最后擦拭/护理 | 按配方完成清洁，护理位置有细微润泽 | 棉片/刷具声，轻拿放瓶子声 |
| 检查与拍照 | 侧面检查、换展示姿势、照片生成 | 克制快门声，可关闭；不遮住成品 |

第二阶段才实现的工艺，其反馈规格同步保留，但不能用“已配音效”描述尚不存在的资产。

## 7. 十指设计板与通用界面

- 指甲卡片悬停显示边界与名称；选中后明确标出手别、手指和图层。
- 素材拖起有轻微抬升，进入可放区域给出落位预览，超界显示裁切/越界。
- 放下有短落位动作和轻声；不必每次自动弹回中心。
- 吸附位置给出轻微定位反馈，吸附可临时关闭。
- 旋转显示角度和方向，缩放显示边界；贴纸不弹跳到无法精确操作的位置。
- 多指应用前预览范围，确认后每指缩略图更新；不同时叠放十个完成音。
- 复制保留图案朝向规则，文字不自动镜像；明显裁切需提示。
- 图层锁定、隐藏、删除和恢复都有即时状态差异；危险覆盖提供可恢复路径。
- 保存成功在实际写入完成后提示；失败保留作品，显示备份入口，音效不冒充保存结果。
- 音乐、工具音、界面提示音、环境音可分别调节并记住设置；总静音始终可快速访问。

## 8. 声音风格与层级

主风格是近距离、细腻、可信的工具材质声。真实感来自匹配接触与材质、自然起落和录音细节，不来自统一把音量拉大。

| 声音层 | 作用 | 相对处理 |
|---|---|---|
| 操作主体 | 锉磨、刷涂、擦拭、贴合 | 最清楚，随接触动作变化 |
| 工具本体 | 电机、风扇、容器、取放 | 比主体克制，区分空转与接触 |
| 状态提示 | 就绪、完成、条件不符 | 短、少且语义稳定，可单独关闭 |
| 顾客表达 | 关键回应、满意反馈，若制作语音 | 清楚可懂，带字幕，不打断精细操作 |
| 工作室环境 | 空调、轻微房间底噪等 | 低存在感，无固定突兀人声 |
| 音乐 | 安静轻音乐，可选 | 自动让位于工具与顾客，不盖住细节 |

耳机模式突出细节，普通扬声器也必须辨识关键动作；无需耳机才能判断是否成功是不合格设计。

空间感以近处工具为中心，左右手可以有轻微声像差异。界面提示居中，不做极端左右声道摆动。玩家转动镜头时避免声像突然跨耳。

## 9. 音频资源交付规格

每个音频条目记录：唯一 ID、动作、材料、起音/持续/收尾、触发和停止条件、变体、循环方式、音量组、来源与授权、状态。音频 ID 与动作状态绑定，不能散落在按钮里随意触发。

建议首批交付类别：

- 手工锉：起音、连续摩擦、抬起收尾；按常见材料提供差异。
- 抛光块、清洁刷、除尘刷、清洁棉：各自连续与短动作素材。
- 电磨：启动、稳定空转、接触、停机；若第一阶段未实现电磨则顺延。
- 胶刷：蘸取、口沿轻刮、点涂、持续刷涂、抬起。
- 瓶盖、工具盘、镊子、甲片、剪片、贴纸、水钻、珍珠：短事件素材。
- 灯具：按钮、适用设备的启动/结束提示、可选风扇循环。
- 界面：选择、确认、撤销、条件不符、阶段完成、保存与拍照。
- 环境和可选音乐：可无缝循环、无突兀接缝。

常重复的短事件建议先提供 3–6 个自然变体，避免连续播放同一个变体；长摩擦声采用可无缝循环的分层素材与平滑过渡，不只是循环一段明显“沙沙沙”。数量是制作起点，最终按试听效果决定。

母带建议保留 48 kHz、24-bit WAV，短工具音优先干净单声道，环境和音乐可立体声。网页发布使用经目标浏览器验证的压缩格式，必要时提供兼容备选；不要在方案阶段承诺某一种编码能覆盖所有设备。

优先采用原创实录或授权清楚的素材，不从视频直接截取或引用未授权商业游戏声音。本轮没有制作、采购或试听音频，音效表不等于已交付素材。

## 10. 连续音的行为规则

接触音由工具接触有效表面且实际发生动作驱动，不能仅由鼠标按住驱动：

- 指针按住但不移动：手工锉不持续磨出声音或材料进度。
- 工具移到甲面外：停止接触声，不继续改动甲面。
- 电磨空转：保留机身声，单独关闭材料接触层。
- 刷子重新接触：恢复自然起音，不每帧重播同一短音。
- 移动速度影响摩擦节奏和强弱，但变化受限、平滑，不能快拖就变尖叫。
- 稳定音高的设备避免随机大幅变调；短材质声优先用真实变体。
- 切换工具、打开阻断操作的弹窗、失去焦点、指针取消和移出有效操作都要正确收尾。
- 十指批量操作不同时发出十倍声量；按动画节奏或合并提示管理。
- 多层同时播放设音量和并发上限，防止削波；重新启用声音不补播静音期间事件。

背景音乐让位采用平滑变化，不突然抽掉全部环境。阶段提示只在真正跨越阶段时触发一次，重复按完成按钮不重播奖励。

## 11. 可读性、辅助与舒适设置

- 重要状态至少以甲面变化/动画、图标或文字两种视觉方式表达，声音作为增强。
- 不能只用红绿区分正确与错误；指名、图标和简短原因同时出现。
- 放大查看、目标轮廓、工具接触提示、吸附强度可调整；默认帮助新手完成。
- 精细操作不使用镜头震动、顿帧或遮挡性光效；完成反馈集中在当前指和步骤栏。
- 减少动态设置关闭过强镜头运动与粒子；灯光局部、平稳，不闪屏。
- 不将触觉反馈当作普遍能力；支持的平台可选轻触觉，不支持也不影响理解。
- 不依赖伤口、痛叫或顾客突然缩手提醒失误。以局部限位、材料状态和说明表达问题。
- 允许独立降低电磨尖锐声音和重复提示音；关闭全部音效后仍可完成订单。

## 12. 一段完整体验示例

订单：顾客带着旧红色胶，想改成短款绿色斜猫眼。

1. 顾客把手放到手枕，参考手机落到桌面。玩家检查每指旧材料和长度。
2. 平面设计板排好十指，选择两到四指猫眼和少量呼应装饰，确认方案。
3. 按旧材料选择卸除路径，工具接触声跟随操作；旧层逐渐减少，残留可见。
4. 逐指检查本甲，锉修自由缘。短促摩擦对应每次有效锉动，粉尘留在甲面。
5. 用刷子扫净浮尘，听到柔和刷声，看见粉尘减少，再按配方完成前处理。
6. 完成本甲建构，在侧面检查厚薄，处理溢边，按步骤入灯固化。
7. 手移入灯中，按钮按下，局部灯光亮起；倒计时结束后一次提示，手回到工作位。
8. 铺底色与猫眼效果层；拿磁铁调整光带，光带本身保持安静，以视觉响应位置和方向。
9. 确认满意后固化锁定布局，再按方案完成装饰和封层。
10. 做最终检查，点问题提示可跳回具体手指；完成后顾客轻转手欣赏，拍照并保存作品。

每一步都能看出材料变化并听见适合该工具的声音。等待动画可压缩，关键判断和定制操作保留。

## 13. 验收标准

1. 同一动作连续做十次，不出现一模一样的强提示音堆叠或显著循环接缝。
2. 手工锉、抛光块、刷子、棉片、甲片、瓶盖和灯具可通过声音区分。
3. 锉磨、擦拭、刷涂的起止与接触区域一致，甲面外操作不产生假进度和接触声。
4. 松手、切工具、失焦、打开阻断弹窗后没有遗留循环；电机停机有正确收尾。
5. 打磨后的轮廓、表面变化和粉尘可观察，刷净会移除相应粉尘。
6. 灯具能展示入灯、就绪检查、启动、运行、完成与取手；提前中断、后台暂停和恢复有明确状态。
7. 每指每层固化状态正确；猫眼布局锁定和表面材质符合所选材料，不靠错误光泽表示完成。
8. 开启和关闭音效都可完成一份订单；提示字幕、图标和对问题指的定位有效。
9. 耳机与普通扬声器分别试听，检查刺耳、低频轰鸣、削波、音量突变和音乐遮蔽。
10. 十指批量操作音量受控，阶段提示只触发一次，静音后重开不补播。
11. 以“本地输入到可见接触响应约 100 ms 内”为初始交互目标，缓存就绪的音效跟随同一动作；在目标设备实际测量后调整，不把目标当作已测结果。
12. 首次浏览器音频解锁、音频加载延迟或失败有明确行为；失败时不影响施工与保存。
13. 手机验证接触、旋转切换和音频中断恢复；运行中性能下降不会造成工具仍响但甲面停止更新。
14. 至少三名新玩家在不用解释全部流程的情况下完成首单，记录对接触、完成和返工的误判，再修订提示；此为后续验证要求，本轮未执行。

## 14. 制作顺序与边界

先做“修形—除尘—刷涂—入灯”这一小段完整声音和视觉样例，校准音色、强度和响应，再扩展到卸旧、贴合、建构、猫眼和饰品。最后补齐取放、开盖、设计板、顾客和相册等外围动作。

第一阶段已有的每项功能都必须配套相应反馈，不把声音整体留到最后。进阶电磨或第二阶段工艺若尚未进入玩法范围，其资产顺延，但一旦开放就按同一标准交付。

后续实现前需确认实际灯具与工具参考、材料兼容流程和音频授权。现实感以参考与试玩验证为准，不将拟音推断写成设备的真实声音。原型未完成前不承诺素材数量、最终音质或性能达标。
