# 《指间诗》美甲工作室升级策划案 v2

日期：2026-10-21  
状态：策划提案，未进入功能开发。以下新增机制、数值与内容量均为设计建议，不代表现有游戏已经实现，也不是行业操作规范。

## 1. 产品方向与现状

**推荐定位：以顾客定制为主线、兼顾自由创作的治愈系 3D 美甲工作室。**

玩家的乐趣来自读懂顾客、解决不同甲况、设计十指搭配，以及亲手把方案做出来。保留目前安静、温暖的工作台氛围，服务挑战以判断、审美与操作反馈为主，不靠催单制造压力。

### 已核对的现有基础

本次访问了公开网页，查看工作台和三份委托，并核对本地 `src/state.js`、`src/main.js`、`src/scene.js` 与 README。网页返回 HTTP 200，基础浏览过程中未捕获页面脚本异常；这不是完整功能回归或真实手机性能测试。

现有能力包括：

- 双手与十指独立编辑，单指、单手和双手观察。
- 圆形、方形、杏仁形与有限长度调整。
- 底色、连续手绘、橡皮、双色渐变。
- 小雏菊、爱心、星星贴纸，以及水钻、珍珠。
- 亮泽、哑光、猫眼、亮片、金属五种整甲质感；已有猫眼磁铁操作。
- 跨指复制、可选镜像、撤销重做、收藏、照片与 JSON 备份。
- 三份主题练习委托，配有五枚指甲的示意预览和明确条件反馈。

主要缺口是：没有真正的顾客档案与逐指初始甲况；没有卸旧、清洁、建构、选片贴合的服务分支；没有十指平面设计板；参考示意与实际顾客订单尚未形成完整关系；工艺仍主要表现为外观编辑。

因此，下一版应先完成一位顾客从入店到交付的闭环，再扩展大量款式、顾客与经营内容。

## 2. 玩家目标与核心循环

目标：在顾客约定的用途、长度、风格和预算内，完成舒适、牢靠、符合方案的十指美甲，并留下值得收藏的作品。

核心循环：

> 接待与看参考图 → 逐指检查 → 确认服务和限制 → 平面设计十指 → 顾客确认 → 按需卸旧与前处理 → 本甲建构或选片贴合 → 3D 实施款式 → 封层与检查 → 顾客反馈、结算、收藏 → 后续回访。

推荐首版节奏为每位顾客约 8–15 分钟；这是待试玩验证的目标，不是已经测得的数据。教学单只引入一到两个新操作，自由创作不限时。

## 3. 顾客系统：每次来店都有明确区别

顾客差异由相互独立的几组信息构成，不能只换头像和一句台词。

| 信息组 | 具体内容 | 对玩法的影响 |
|---|---|---|
| 手部与甲床 | 手型、肤色、每指甲床宽度和长度、曲率、自然生长方向 | 调整甲片尺寸、设计比例与观察角度；肤色不影响难度或得分 |
| 每指现状 | 本甲自由缘长度、旧胶或旧甲片、局部缺损、灰尘和污垢、残留材料 | 决定卸旧、清洁、修整和补片范围 |
| 服务选择 | 本甲服务、全贴甲片、卸旧后重做、局部维修 | 决定施工路径和材料 |
| 款式目标 | 参考图、目标甲形、色系、猫眼/法式等工艺、重点手指 | 决定十指方案与验收要求 |
| 日常需求 | 打字、弹琴、旅行、婚礼、拍照、偏好低凸起等 | 限制长度、装饰高度和重点手指 |
| 合约约束 | 预算、可接受的改动、必须保留与明确不要的元素 | 防止玩家凭个人喜好覆盖顾客诉求 |
| 关系与历史 | 过往款式、喜欢的元素、返店原因 | 带来后续订单和个性化对话 |

**检查对象必须细到每一指。** 同一位顾客可以九指完整、一指掉片，也可以只有两指有明显残留。不能用“整双手都是脏甲”替代状态设计。

初始甲床宽度、甲床长度、曲率属于顾客特征；修形只能改变可修的自由缘，不能把短甲床直接拉成长甲床。需要额外长度时，改为顾客认可的贴片服务，或协商改款。纸托、半贴延长等路线留到后续。

订单采用受控组合：先确认素材、服务和长度相互兼容，再生成顾客。早期用固定教学单；熟悉后，在兼容范围内变化甲况、配色和重点手指，避免出现无法完成的随机任务。

## 4. 顾客带来的样式图与沟通

每位服务顾客都带参考图，形式可以是手机截图式卡片、十指样式图或杂志式局部细节。首版采用原创/有许可的内置图片，且每张图有对应的结构化款式资料。

订单页同时展示：

1. 原参考图：可放大，可固定在工作台旁。
2. 必须满足：例如短方圆、奶白底、指定两指猫眼、禁止大颗钻。
3. 可以调整：例如左右手不必完全一样，花朵位置可自行安排。
4. 生活限制和预算：长度上限、装饰高度、价格范围。

对话只提供会影响方案的选择，例如：“图片是长杏仁，你希望保留长度还是改成方便打字的短款？”选择结果写进订单，后续按确认后的要求评分。

参考图与顾客甲况冲突时，应在设计阶段提示并协商。不得等作品完成后才以未披露要求扣分。顾客改变已确认需求时，明确更新订单、价格和所需返工范围。

任意用户图片导入可作为后续自由创作工具，但不能承诺自动识别工艺、逐指布局或主观审美。内置订单的评价来自事先编排的款式资料，不能宣称是 AI 看图打分。

## 5. 十指平面设计板：先设计，再施工

### 5.1 设计板是什么

它是基于当前顾客甲床、目标甲形和长度的**数字施工蓝图**。本甲服务与贴片服务都使用它；它不意味着玩家已经制作好十枚实物甲片，也不会自动完成建构、粘贴、磁吸或固化。

### 5.2 界面布局

- 左侧固定参考图和顾客要求。
- 中央上下两排展示左右手，共十枚甲面，明确标注“左拇指”等名称，指根和指尖方向一致可辨。
- 右侧素材抽屉：颜色、图案贴纸、法式模板、工艺效果、立体饰品。
- 下方是当前指的图层和整套完成状态。
- 设计板甲形按顾客预计施工结果生成，保留尺寸比例差异。另提供统一放大编辑窗口，避免小指难点选。

### 5.3 像贴贴纸一样设计

- 拖入花、蝴蝶结、星星、蕾丝、金箔等素材，移动、旋转、缩放、调色。
- 用模板快速排法式边、色块、波点和渐变；保留自由手绘。
- 每指独立设计，也可框选多指统一底色。
- 复制单指、复制到对侧对应指、整组呼应搭配。
- 支持“主视觉指 / 呼应指 / 留白指”的提示，避免十指都堆满装饰。
- 允许左右手不对称，不以完全对称作为默认合格条件。
- 图层可选中、锁定、隐藏、排序和删除；立体饰品有独立层级，不能随意排到甲体下面。
- 效果卡分清“贴纸”和“工艺”：猫眼、渐变等卡片用于预览和安排，施工时仍需要对应工具。

### 5.4 确认与施工关系

进入施工前，十指都应有明确的款式安排；纯色或刻意留白也算设计完成。系统检查明显冲突，例如超出顾客允许长度、饰品高度过大、预算超限或设计超出甲面。

顾客确认后保存一个方案版本。3D 工作台显示小尺寸十指蓝图，并可查看目标叠加轮廓；叠加预览不改变已施工状态。

在 3D 上，玩家仍需完成上色、指定工艺和装饰放置。普通贴纸提供目标位置吸附帮助；高难订单再降低吸附。掌握某项基础动作后，可使用批量辅助，但明确显示会执行哪些动作。

回到设计板改稿时保留已施工内容，标记差异。尚未施工的指更新目标；已完成的指由玩家选择保留或按工艺返工，不得悄悄替换成新成品。

最终长度或甲形变化时，提示重新适配蓝图：小幅变化可预览重排，明显裁切必须确认。文字类贴纸默认不随跨手复制反转字形，镜像几何图案需单独选择。

## 6. 服务分支与施工顺序

| 服务 | 起始状态示例 | 核心流程 | 主要判断点 |
|---|---|---|---|
| 本甲建构上色 | 干净本甲或少量污垢，无旧甲片 | 检查 → 按需清洁 → 修形与前处理 → 配套底层 → 建构与固化 → 表面修整 → 款式 → 封层 | 保留真实甲床；建构厚度与顶点；顾客长度限制 |
| 全贴甲片 | 本甲较短，顾客同意贴片 | 检查 → 按需清洁与前处理 → 逐指选片试贴 → 兼容的贴合流程与固化 → 修长修形 → 款式 → 封层 | 宽度、曲率、气泡、偏斜和边缘贴合 |
| 卸旧胶后重做 | 本甲上有旧色胶或可卸材料 | 识别旧材料 → 匹配卸除流程 → 去残留 → 重新检查 → 进入新服务分支 | 卸旧后才看到的实际甲况；不能把残留直接覆盖 |
| 卸旧甲片后重做 | 顾客带旧甲片、部分翘起 | 分指卸除旧片与残留 → 重新检查 → 确认最终服务 → 本甲建构或重新贴片 | 旧片状态逐指不同；不能简单整手清空 |
| 局部维修，后续加入 | 一指掉片，其余保存良好 | 选择维修范围 → 局部处理 → 补做并匹配旧款 | 不误改完整手指；区分补一指和整套换新 |

污垢、旧材料和目标服务是三个独立维度，可以同时存在。只在需要时加入清洁，不要求每位顾客重复相同流程。

本方案把“建构”设为游戏中本甲凝胶套餐的标准步骤，以满足本次玩法需求；这不表示现实中任何本甲美甲都必须建构。首版全贴甲片采用独立、兼容的材料路线，不强制重复完整本甲建构；具体产品流程需要后续由专业美甲师审核。

### 6.1 检查与清洁

检查时旋转手部或切换指尖视角，观察甲面、边缘和自由缘。可见污垢采用柔和、可辨识的灰尘/残留效果，不靠猎奇画面制造挑战。

工具包括软刷、清洁棉、修形锉、浮尘刷等，分别对不同目标生效。轻刷让脏污逐渐消失，清洁后甲面呈现干净状态；修形后出现浮尘，需要再刷净。清洁与前处理按服务配方排序，不做“一次清洁覆盖全部步骤”的假流程。

用覆盖率、残留范围和清洁均匀程度提供反馈。推荐难度有轮廓提示，挑战难度只在检查视角显示。明显破损或不适宜服务的特殊事件以暂停该指服务、调整订单处理，避免设计成继续打磨才能过关的任务。

### 6.2 卸旧

让玩家辨别旧色胶、全贴甲片和残留材料，选择匹配的工具流程。可卸材料和需打磨材料不能只换个动画却完全相同。

首版将卸旧简化成两条受控路径，工具覆盖让材料分层变薄，再清除残留。旧甲片通过处理后的松动与脱离表现完成卸除，不以暴力撬片为成功操作。进度用“剩余旧材料”表现，避免玩家误以为应磨薄本甲。

卸旧后重新展示实际本甲状态，可能需要局部修整或修改原先建议。若与方案冲突，进入短对话确认，不强行执行不合适服务。

### 6.3 本甲建构

玩法围绕“放胶 → 引导铺开 → 看侧面 → 固化 → 修整”设计。

- 胶滴量影响厚薄；用刷子拖动形成有限范围的高度分布。
- 从侧面检查平顺度、顶点区域和自由缘厚度。
- 目标范围根据甲长与服务设定，不能所有顾客套同一个顶点。
- 胶未固化前可回收或补加；固化后再修改则需要修整或补胶。
- 亮色轮廓与文字共同提示溢胶位置，提供补救动作，不靠一次失误判整单失败。
- 建构本身不等于延长，也不能凭空改变顾客甲床。

实现上采用可控的低分辨率高度数据与几何变化，优先保证厚薄、顶点、侧面可读，不以真实流体为首版目标。

### 6.4 选片、贴合与修形

试片盘按尺寸和曲率分组。逐指试贴时显示两侧覆盖、弧度和居中状态；提供合适候选，避免玩家在大量近似型号里盲试。

贴合阶段由玩家控制位置、角度与施压过程：可看见气泡、偏斜或边缘间隙。固化前能抬起重贴，固化后采用局部返工路径。完成后再按设计板修长度和自由缘形状。

拟新增短方圆、椭圆、梯形/芭蕾等甲形。甲形选择受实际长度约束：短本甲不能单靠修锉得到长尖甲。首版修形使用目标轮廓和有限形变，后续再考虑自由修锉。

## 7. 美甲工艺：让种类产生不同操作

| 类型 | 玩家主要操作 | 成品变化与反馈 | 推荐批次 |
|---|---|---|---|
| 纯色、透色、果冻 | 控制涂布覆盖、层数与透明度 | 露底、过厚、边缘整洁度可见 | 第一阶段 |
| 法式 | 选模板、调整微笑线，沿边涂绘 | 线条位置、宽度与各指呼应 | 第一阶段 |
| 渐变 | 涂两色并刷开或点拍过渡 | 交界从生硬变柔和 | 第一阶段 |
| 猫眼 | 涂猫眼胶、移动和旋转磁铁，满意后固化 | 光带位置、方向、宽度与转手后的变化 | 第一阶段 |
| 贴纸、手绘 | 对照蓝图贴合，或沿辅助线绘制 | 图案位置、方向、层次与留白 | 第一阶段 |
| 水钻、珍珠 | 点固定材料、放饰品、调整朝向与固定 | 高度、间距、稳固和生活需求冲突 | 第一阶段 |
| 细闪、亮片、金箔 | 控制密度、区域与疏密 | 局部高光与纹理；避免只能整甲切换 | 第二阶段 |
| 镜面粉、金属 | 使用对应底层和材料工具完成效果 | 金属反射随视角变化 | 第二阶段 |
| 晕染、大理石 | 点色后控制扩散与纹路 | 产生可控的不规则图案 | 第二阶段 |
| 浮雕、立体凝胶 | 沿轨迹挤出/放置并固化 | 明确的厚度、投影与侧面轮廓 | 后续扩展 |

现有猫眼、金属、亮片等外观能力可复用，但应将“颜色”“效果工艺”“最终封层”拆开。猫眼与渐变可以组合，局部贴纸可以叠加，亮泽/哑光作为封层选择；不再让所有效果挤在一个互斥选项里。

工艺仍受材料配方与可实现组合限制。比如哑光会改变猫眼的观看效果，方案预览应直接显示，不宣称所有组合都有相同表现。

### 猫眼专项

首版优先做好斜光、居中光和宽光带三个可辨识目标：

1. 在设计板指定用猫眼的手指、底色和目标光带。
2. 在 3D 甲面铺猫眼效果层。
3. 磁铁移动改变光带位置，旋转改变方向，距离控制集中程度。
4. 玩家松手查看，再决定继续调整或固化锁定。
5. 固化后磁铁不再改变已完成光带；重做需进入对应返工流程。
6. 转动手指时光泽响应仍然变化，说明“锁定的是磁吸布局”，不是把光线画死在纹理上。

后续再扩展圆光、月牙、丝绒和多色变化；不承诺磁性粒子物理仿真。

## 8. 避免十指重复劳动

每种新动作先通过一到两枚指甲教学，再开放“对已选手指重复基础操作”。玩家决定范围，操作前展示会影响的手指；完成动画后逐指更新，不能误改已经做好的局部款式。

适合批量辅助：基础清洁、同一底层、同色底色、相同贴纸模板、满足条件后的合批固化。

保留手动重点：甲况判断、逐指选片、首次建构、问题指维修、主视觉指设计、猫眼布局和高饰品放置。其余简单呼应指可使用方案引导和吸附。

一次小失误产生局部补救：擦去溢色、移动贴纸、未固化重贴、局部补胶，不要求整套重做。自由创作保留完整撤销；服务模式将尚未确认的动作与已固化施工阶段区分，教学/舒适难度可提供额外回退。

固化以简短动画压缩等待，禁止让玩家重复空等真实时长。按配方安排顺序，不把建构、猫眼、封层合并成一次统一照灯。

## 9. 评分、顾客反馈与轻经营

### 9.1 可解释的评价

推荐初始权重如下，需通过试玩再调：

| 维度 | 权重 | 依据 |
|---|---:|---|
| 订单符合度 | 40 | 已确认的长度、甲形、指定色系、工艺和禁用元素 |
| 施工质量 | 35 | 前处理、残留、建构厚薄、气泡、溢边、固定等适用项目 |
| 与确认方案一致性 | 15 | 重点手指、图案方向、装饰位置及允许偏差 |
| 已约定的个性化偏好 | 10 | 留白、装饰密度、左右手关系等明确条目 |

不同服务只计算适用项目并在维度内归一化；本甲单不能因为没有贴片气泡数据而失分。明确标记“必须满足”的条件不能被其他高分抵消，未完成时提供返工入口。

顾客偏好必须在接单时披露。未确认的主观审美不纳入扣分；沙盒不强制评分。

反馈示例：“左手无名指的斜猫眼和参考很接近；右小指前缘仍有一处溢色，可以清理后再交付。”系统同时提供点击跳转到问题指，保留顾客自然语言回应。

### 9.2 结算与成长

- 服务前确认套餐、材料升级与价格，不能交付时突然加收费用。
- 收入用于解锁材料、模板和少量工作台陈设；基础工具始终够完成当前订单。
- 不设体力、强制倒计时、材料缺货等额外压力为首版前提。
- 老顾客回访提出有意义的后续需求，例如上次喜欢猫眼，这次需要旅行短款。
- 作品相册记录顾客、十指方案、前后对比、工艺标签和回访历史。
- 后续可加入“新设计、延续旧款、局部补片”的返店选择，避免每次都重置为陌生顾客。

## 11. 新手引导与模式

第一单用一份简单的纯色加两枚贴纸订单，分三段教学：看要求并检查、排十指方案、做一指再批量辅助完成其余基础步骤。该单只引入基础建构，不同时教学卸片、复杂猫眼和立体花。

第二单引入按需清洁和法式；第三单引入全贴甲片；之后再引入卸旧和猫眼。每次只新增少量操作，新规则当场可见，不用长篇说明弹窗阻断。

建议提供三种入口：

- 顾客服务：完整流程，有订单和反馈，是主模式。
- 自由创作：直接进入设计与展示，保留现有作品自由编辑能力。
- 工艺练习：选择一只手/单指，单独练建构、贴片、法式或猫眼。

舒适辅助包含大热区、吸附、批量基础动作和可关闭的操作音。挑战设置后续增加，不作为首版完整性条件。

## 12. 视觉、声音与界面优化

维持奶油白、木色与低饱和玫瑰色的工作室氛围，但增强皮肤、甲床、本甲自由缘和甲片边缘的区别。近景优先表现甲缘、甲床色、胶层厚薄、光泽和贴合关系。

手模需要宽窄与曲率差异，而不仅是整体缩放；若替换为精细模型，仍需保留稳定的十指编号、甲面坐标和饰品附着。

工作台按阶段更换工具盘：接待看参考、设计用贴纸盘、前处理用清洁工具、施工用对应材料。当前所需工具突出显示，其余可收纳，避免一次铺满全部美甲种类。

3D 施工界面推荐：中间大手部视图；左侧当前服务步骤；右侧可固定参考图与局部细节；下方十指进度。点问题指可自动切到侧面或近景。

声音采用轻刷、修锉、贴纸剥离、饰品落位、磁吸工具移动与灯开关的短反馈，默认音量克制，可独立关闭。避免持续噪声和夸张成功特效遮挡指甲。

触屏将编辑和旋转明确分开；支持双指缩放、撤销与替代数值调节。小尺寸装饰提供放大编辑与点选列表，不能只靠精准拖拽。状态同时用图标、文字和颜色表达；减少动态选项关闭强动效。关键参数能通过按钮/滑杆和键盘焦点调整。

### 12.1 追加交互与声音要求（2026-10-21）

打磨、抛光、除尘、刷涂、贴合、照灯和工具取放的鲜明反馈，以及贴合实际动作的生动音效，纳入第一阶段核心验收，不作为最后附加的装饰。完整动作状态、逐项反馈矩阵、照灯流程、音频资源与验收要求见 [《交互反馈与拟真音效细案 v2.1》](交互反馈与拟真音效细案-v2.1.md)。

每个已开放操作都应覆盖选中、接触、持续、离开、完成、条件不符和返工反馈；视觉说明材料变化，声音匹配工具和接触。首版所用材料需具有对应反馈，后续才开放的工艺随功能一起交付。

## 13. 实现边界与数据要求

复用现有 Three.js、甲面 UV、绘画、饰品和收藏能力。为完成本次闭环，数据上至少区分：

1. 顾客特征与逐指初始甲况：本次订单的原始基准。
2. 顾客订单与参考资料：服务路径、约束、十指目标和评分条目。
3. 已确认的十指设计蓝图：版本、图层与允许变化。
4. 当前施工状态：旧材料剩余、清洁、建构、贴合、涂绘、固化和返工。
5. 已交付作品与顾客记录：成品、照片、评价和可继续创作副本。

设计板和 3D 使用同一套甲面坐标与可复用的外观渲染规则，但蓝图与施工进度必须分开存储。复制外观不复制顾客甲床尺寸、清洁结果、建构质量或固化状态，防止一键复制意外替代逐指施工。

服务采用带前置条件的步骤状态：不能在不兼容旧材料上直接封层；能在未固化时继续调整；固化后转入明确返工路径。批量固化应逐指核对前置条件，只处理已就绪的手指。

保存当前顾客、蓝图和施工进度，刷新后能从阶段继续。存档升级应兼容现有 v1 作品，将其作为自由创作作品读取；不能让旧收藏因新增顾客字段而失效。新格式导入沿用校验、容量错误提示和备份能力。

性能目标先按桌面浏览器和常见触屏设备分别实测制定。第一阶段不承诺照片级手部、无限图层、真实胶液流动、真实磁性粒子、自由切削实体或任意参考图理解。视觉可信度优先投入在操作能看见的局部，而非不可控物理计算。

## 14. 分期与优先级

### 第一阶段：顾客服务闭环，必须整体可玩

范围：六位固定顾客和配套原创参考图；逐指甲况；十指设计板；按需清洁与两类卸旧；本甲建构与全贴甲片两条新做路线；纯色、基础法式、渐变、猫眼、已有贴纸与饰品；确认方案、局部返工、解释性评价、保存恢复与作品展示。

建议内部按以下顺序落地，但对外交付以完整闭环为准：

1. 先用一位本甲顾客串通订单、设计板、3D 施工与结算。
2. 加入贴片服务、按需清洁与卸旧状态，补齐路径。
3. 加入猫眼施工锁定、图层和方案差异，完善六位顾客。
4. 做存档兼容、触控适配、完整流程验证与性能调整。

### 第二阶段：丰富工艺与复访

局部补片与补色、老顾客历史、局部金箔亮片、镜面粉、晕染、新甲形和更多兼容订单组合。加入少量材料与工作室装饰解锁。

### 后续扩展

立体凝胶与复杂浮雕、其他延长体系、自由穿戴甲商品制作、顾客自带图的手动参考模式，以及更丰富的店铺经营。

自由穿戴甲商品制作是独立服务：玩家可能真的先制作十枚实物甲片再交付。它与当前“设计板先排版、3D 手上施工”的顾客服务不同，后续单独定义，避免首版流程混淆。

不在本轮给出开发工期或商业回报数字。应先完成一个建构/贴合与平面映射的小型验证，再估算工作量。

## 15. 第一阶段验收标准

1. 至少六位顾客带不同需求和参考图，覆盖本甲、贴片、卸旧胶、卸旧片以及需清洁情境。
2. 同一顾客能有逐指不同的甲况；不需要的清洁和卸旧步骤能正确跳过。
3. 十指设计板支持独立布局、多指应用、复制、图层调整与方案确认；有意留白不算漏做。
4. 宽窄和曲率不同的甲床影响试片；短本甲不能通过甲形按钮直接获得不合理长甲。
5. 建构能从侧面看出厚薄变化；贴片能看出错位和气泡，并允许对应补救。
6. 设计预览不会自动完成施工；在 3D 上能对照蓝图操作并查看差异。
7. 猫眼磁吸在固化前可调，固化后锁定布局，观察角度仍能改变光感。
8. 各条服务路径只计算适用评分项；必须条件未完成时给出具体指位和修正入口。
9. 简单基础动作有明确范围的批量辅助；关键定制操作仍有手动参与；等待动画可合理压缩。
10. 刷新恢复当前服务，旧版作品可继续打开，保存失败不显示成功。
11. 桌面及至少一台真实触屏设备完成完整订单，验证点选、旋转、缩放、撤销和重点装饰放置。
12. 扩展后继续保留自由创作、作品收藏、照片导出与备份恢复。
13. 已开放工具的接触与离开决定连续声起止；打磨、刷涂、棉片、甲片、瓶盖和灯具使用可区分音色，切换工具或失焦无遗留循环。
14. 打磨能看见轮廓/表面与浮尘变化；照灯包含入灯、待固化层检查、启动、运行、中断、结束和取手，每指每层状态正确。
15. 静音时仍可辨认操作和问题；耳机及普通扬声器均验证工具声清晰度、重复感、音量与同步，未试听资产不声称音质达标。

## 16. 待验证假设与后续交接

默认建议是顾客服务作为主入口、自由创作保留；优先支持桌面与横屏触屏；采用原创内置参考图；不设强制倒计时。这些均为方案选择，后续可按用户反馈调整。

需要验证的风险：十指施工是否重复、设计板与曲面映射是否易懂、不同甲况能否直观看出、猫眼在不同设备上是否足够清晰、建构和贴合辅助是否能让新手完成。通过一位完整顾客的原型试玩，再调整操作时长和帮助强度。

后续交给制作规划确定依赖和批次，再进入实现。专业服务顺序与材料兼容关系需请美甲师校对；本策划为游戏机制，不提供现实操作教学。

本轮仅新增策划文档，未修改游戏功能、迁移站点或执行发布。访问验证限于当前网页基础界面；本文新增玩法尚未开发或试玩。
