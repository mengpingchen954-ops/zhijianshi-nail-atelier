## 怎样玩

1. 翻开预约本，选择一位带着参考图来的顾客。八位顾客分别覆盖本甲、清洁、卸旧胶、卸旧甲片、全贴甲片、猫眼及单指维修。
2. 顾客只给参考图和需求，平面设计板从空白开始（单指维修保留其余九指）。由玩家安排十指：选色、选工艺、拖贴纸、调整装饰大小与角度、图层锁定/隐藏/排序、跨指复制。顾客的甲形、色系与重点工艺须满足，装饰指位由玩家安排；没有一键代做方案。
3. 确认方案后开始 3D 服务。下方选指进入近景；点击检查；试片按住拿起、拖到甲根后放下。清洁、刷涂与建构沿实际拖动轨迹铺开，抬笔不会连接两段，湿润层有局部反光；打磨仅沿自由缘横向往返，甲形逐渐修短并扬起粉尘。
4. 第一指亲手完成后，可辅助处理本手其余指，减少重复。另一只手由玩家另行选择。
5. 全贴服务逐指选合适宽度和弧度，试贴后从甲根向自由缘平稳压合，透明片逐步落下，气泡随压合前沿排出。猫眼移动磁铁并调整方向，确认布局后照灯锁定。
6. 基础层、款式层、封层各自照灯；选择左手或右手后，整只手的五指一起进入固化灯。灯腔按本手五指空间范围准备，透明查看罩显示拇指也在灯内；完整送入后感应亮灯、风机和倒计时才启动，取出后才解锁。提前取手立即熄灯并中止本轮，可缩短等待动画。
7. 交付后收藏完整作品、拍照下载或导出可编辑 JSON。自由创作入口保留旧版画笔、橡皮、渐变、装饰、收藏与备份能力。

设计板用「短甲／中长甲／长甲」显示长短，绿色滑杆区间代表顾客可接受范围，拖动时即时预览。甲形与长度分项显示完成指位数，未满足要求时可点击具体手指直接定位到修改控件；保留玩家设计与原有内部长度数据。

编辑时右键拖动旋转，滚轮缩放。触屏先点眼睛切换旋转，再点回操作；支持双指缩放。侧面查看建构厚薄。Ctrl+Z / Ctrl+Shift+Z 撤销/重做本阶段，已确认的前一阶段不会被误撤回。

## 声音与存档

工具接触有效甲面并移动时产生摩擦/刷涂声，松手、失焦和换工具时停止。设置中的音乐播放器可选择 `E:\Meijia\音乐` 提供的 6 首伴奏，上一首/下一首、播放暂停和伴奏音量独立控制，曲目和音量会记住；播放完自动接下一首。工具音、提示音、伴奏与环境音独立调节。声音需要首次点击后启用。

音效是本项目原创程序拟音，包含 41 个 WAV 资源：不同频谱与颗粒结构的锉磨、刷毛、清洁棉、湿胶、钻机、风机，塑料弯曲、盖子、灯机开关与落位事件；接触速度、笔压力、左右位置控制音量、滤波与声像。6 首伴奏是用户从本机音乐目录提供的 MP3，保留原文件中的 watermark，不冒充项目原创。环境音默认关闭；不是实地工具录音。生成脚本及伴奏来源说明随源码提供。

服务进度自动保存于当前浏览器。设置可导出/恢复完整服务备份；清除网站数据或换域名不会自动迁移存档，建议定期备份。旧版 v1 收藏仍从自由创作入口读取。

## 验证

```powershell
npm test
npm run test:salon
npm run test:interactions
npm run test:music
npm run test:length
npm run test:audio
npm run test:salon:edges
npm run test:browser
npm run test:edges
npm run test:modules
```

`test:salon` 用浏览器真实鼠标操作跑通八位顾客，覆盖刷涂、试片、磁吸、照灯、提前取手、刷新恢复、收藏与下载。可设置 `GAME_URL` 指向生产预览或公开站点，设置 `CLIENTS=lin,wen` 限定订单。自由创作测试自动使用 `?mode=free`。

`test:interactions` 使用独立施工夹具和实际鼠标输入，检查停手不推进、局部刷涂像素与抬笔留白、湿润层、甲片拖放和排泡、左右手五指灯腔边界、感应启停、完整取手以及手机视口。`test:music` 检查 6 首 MP3 按需加载、选曲、循环切换、播放暂停、音量、刷新恢复、失效重试与移动端布局。`test:audio` 检测实际空闲/接触/释放音频输出；不等同于人工听音验收。

`window.render_game_to_text()` 输出当前服务、逐指进度、照灯和音频状态；`window.advanceTime(ms)` 可推进游戏固化计时，供验证使用。

桌面与手机视口均有浏览器验证；未将视口模拟称为真实手机/Safari 验证。3D 手部是程序化模型，工艺为可控模拟，不模拟真实流体、磁性粒子或无限自由修锉，也不作为现实美甲操作教学。
